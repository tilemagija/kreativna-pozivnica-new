## 9. Правила количине и попуста (потврђено од власника)
- **Минимална количина: 50 ком.**
- **Може и мање од 50**, али се тада **доплаћује „припрема за штампу" = 4000 дин** (фиксно; покрива паљење машина, сечење, паковање, одлазак до поште — исто траје за 50 и за 500 ком).
- **Количински попуст:** тренутно ад-хок (нпр. велика поруџбина ~60.000 → 10% из доброг ока). **Оставити као опционо поље да се дода касније** — НЕ фиксне степенице сада.

## Формула цене (за потврду)
```
Укупно = Количина × (папир + додаци_по_комаду + коверта + печат_и_додаци)
       + флат_дизајн (ако се бира: 800 / 4000 / 4500)
       + (Количина < 50 ? 4000 : 0)      // припрема за штампу
       − попуст (ручно, касније)
```
- „додаци_по_комаду" = двострана штампа +20, ручно цепкане ивице +20, заобљене +10.
- „печат_и_додаци" = печат 40 / +златни листићи 50 / +татарика 70 / тракице 40–80 / нитне +10.
- Дизајн (800/4000/4500) је **једнократан** (није по комаду).

- Крем рељефни папир + златни листићи
- Крем рељефни папир + дебља рељефна коверта + печат + сатенска тракица

## Отворена питања (за касније)
- Које боје иду за коју врсту папира (тачно мапирање светлијих нијанси за позивнице).
- Да ли „дизајн" (800/4000/4500) увек иде уз позивницу или је опција.
